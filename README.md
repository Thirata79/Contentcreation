# 現場改善メディア ／ 予約制ビジネスの業務OS

> 「トレーナー」ではなく **「予約制ビジネスの業務OS設計者」** として、
> 現場の違和感を構造化し、テンプレ化し、最終的にツール（SaaS）化する。

このリポジトリは、上記ポジションを実行に移すための **戦略ドキュメント** と
**SNS発信コンテンツ（30投稿）** をまとめたものです。

---

## 事業の正体（核心）

```
現場の悩みを解決する
予約制レッスンビジネスの「業務OS」メディア
```

- **フロント**：メディア（SNS発信）
- **中間**：業務改善コンテンツ（テンプレ・チェックリスト）
- **バック**：SaaS・ツール化

### 成長フェーズ
1. 現場の違和感を発信する
2. 構造化する
3. テンプレ化する
4. ツール化する

---

## なぜ「業界」ではなく「構造」で括るのか

ジム・空手道場・ピラティス・治療院 ——
業種はバラバラでも、業務構造は **「予約制レッスンビジネス」** として同じ。

| 共通構造 | 具体例 |
|---|---|
| 予約・キャンセル | 電話/LINE/紙、ダブルブッキング、無断キャンセル |
| 顧客との連絡 | LINE手作業、返信タイミング、テンプレ不在 |
| 継続・LTV | 回数券、月謝、離脱の早期発見 |
| 集客導線 | Web/SNS→予約までの段差 |
| 単価・費用対効果 | 値付け、客層、時間あたり利益 |

→ 業界で分けず、**構造で統一する**ことで横展開（SaaS）が成立する。

## 使い方
1. `docs/` で方針を固定する（ブレ防止）。
2. `content/posts.md` の30投稿を順次発信する。
3. 各投稿は **仮説検証ログ**。反応を `posts.csv` のスコア列に記録し、勝ち筋をテンプレ化→ツール化に回す。
