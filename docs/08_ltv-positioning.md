# 08. 北極星：継続（LTV）特化

> **「集めるな、続けさせろ」**
> 予約制レッスンビジネスの **継続（LTV）設計者**。

これまでの検討（トレーナー飽和／業界特化メディアの天井／予約SaaSの激戦＝MOSH）を
全部回避して残った、**唯一の空き地**がここ。集客は競合だらけ、継続は誰も握ってない。

---

## なぜ継続(LTV)に特化するのか
| 軸 | 中身 |
|---|---|
| 空き地 | 競合全員（ge_ge_ge・中島・とき・MOSH・集客業界）が**集客に集中**。継続は無人 |
| 本当の制約 | 3ヶ月離脱／半年で4割退会／「新規でしか成り立たないモデルは詰む」（リサーチ済） |
| 金の在処 | LTVは掛け算。1%の継続改善 ＞ 大量の新規。商売の利益はリピートに乗る |
| 時流 | 2026は二極化＝「広告止めても指名・紹介が**回る側**が勝つ」。それは継続の結果 |
| 差別化 | 「継続の人」は唯一無二。「集客の人」は飽和 |
| トーン | 煽らない。仕組み・信頼の上品なブランドになる |
| 横展開 | 継続設計は業種非依存（ジム/ピラティス/ヨガ/治療院/教室で構造同一）→ 後で拡張可 |

---

## ★最重要ルール：「継続」という言葉で発信を始めない
人がビビっと反応する痛みは **「客が来ない（集客）」**。
継続の痛みは**ぼんやりしてて、客のせいに誤診される**（「合わなかったんだろう」）。
だから「継続設計」と看板を出した瞬間、地味で**誰も見ない**。

### 発信アーキテクチャ＝「集客の顔で入り、継続に着地」
```
① フック層   … 集客の"felt pain"で止める（新規追うの疲れた／体験来るのに続かない）
        ↓
② 反転（署名）… 「問題は集客じゃない。継続だ」← あなたの必殺技
        ↓
③ 着地       … 継続設計／LTV（＝商品・専門性の正体）
```
**「継続特化」は中身（商品・専門性・正体）の話。発信の入口は集客の痛みを借りる。**

---

## 署名メッセージ（ブランドの核）
> **「集客をやめろ。バケツの穴を塞げ。」**
> 新規集客は麻薬。**穴の空いたバケツに水を注ぎ続けてるだけ**。
> 注ぐ量（集客）じゃなく、穴（離脱）を見ろ。

→ 「穴の空いたバケツ」一個で、図解・一貫性・差別化が全部立つ。

---

## 発信の柱（コンテンツピラー）
1. **離脱の仕組み** … なぜ辞めるか／辞める順番（間隔の伸び→次回空白→連絡途切れ→退会）
2. **次回予約** … その場で次を埋める。継続率の土台
3. **関係構築/カウンセリング** … 通う理由を再確認する接点
4. **紹介設計** … 偶然待ちをやめる（瞬間×手段×返礼）
5. **会員制・サブスク・ストック** … 刈り取り型から積み上げ型へ
6. **価格と継続** … 安売りは続かない。価値で継続させる
7. **二極化** … 広告依存を抜け、指名・紹介が回る側になる

## マネタイズ階段（※ツールはMOSH等に乗ってOK。SaaSにこだわらない）
```
発信（継続の気づき）
   → 継続診断・テンプレ配布（リード）
   → 継続設計の講座／伴走（コア）
   → 継続が回る仕組みづくり（伴走・月額）
```
※ 継続を売る商品は、それ自体LTVが高い（伴走・月額が自然）。
   **自分のビジネスも継続型になる＝言行一致**。これが美しい。

## ターゲット（最初の刺し先）
- **既にある程度生徒がいて、離脱で消耗してる**個人インストラクター（ピラティス/ヨガ）。
- ※開業前/新規ゼロ層は集客脳なので二次。まず「血が出てる人」に止血を売る。

## 横展開ロードマップ
ピラティス/ヨガで確立 → ジム/治療院/教室へ（継続は業種非依存）。
