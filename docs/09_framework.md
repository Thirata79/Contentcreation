# 09. フレームワーク：引き算の継続設計（LTV）

> **「足すな、消せ。」**
> 継続(LTV)は、すごいことを足すゲームではない。**辞める理由としんどさを"消す"ゲーム**である。

15年のパーソナルトレーナー経験（最長14年継続／日本最上位の池で）から抽出した、
業種を超えて使える継続(LTV)の理論。`docs/08`（北極星）の中身＝これ。

---

## 核心の一行
> 継続(LTV) ＝ **① 正しい客を"入れる"（選定）** × **② 辞める理由を"消し続ける"（引き算）**
> そして語れるのは、**日本一の池で15年・最長14年、最激戦で選ばれ続けた目撃者**だけ。

---

## 哲学：継続は「引き算」
世間は「もっと足せ（hopium）」と叫ぶ。真実は逆。**完璧でゼロ。プラスは無い。アウトを踏むと終わる。**

| 領域 | 世間の誤解（足し算） | 真実（引き算） |
|---|---|---|
| 選定 | いい客を増やす | 間違った客を**入れない** |
| 感じのよさ | 魅力を足す | しんどさを**消す** |
| 外見 | カッコよくする | 気持ち悪さを**消す** |

→ すべてに **臨界点（即アウトのライン）** がある。継続とは、この臨界点を踏まない運用の積み重ね。

★唯一の例外＝**信頼の加点**（時間が筆頭、社会証明も同類）。これだけは安く・消えず、**halo（後光）を生んで引き算を楽にする**。dazzle加点（華・すごさ＝消える）とは別物。詳細は第2層。

---

## 第1層：選定（池 × 価格 × 価値観）
**LTVは"続けさせる技術"の前に、"誰を入れたか"で8割決まる。**

- **① 場（池）**：単価と購買頻度は**働く場所で決まる**。過処分所得が高い池を狙う。
  - 努力では池の経済（単価×頻度の天井）を覆せない。安い池で始めた瞬間、一生離脱と戦う。
  - ※ 原点＝アメリカンクラブ（富裕層・駐在・会員制＝継続文化）。**環境が選定をやってくれていた**。
  - ★教訓：客を変えるな。**正しい客が既に集まる池に行け／自分の業種での"その池"を作れ**。
- **② 価格**：価格は利益のためでなく **"継続フィルター"**。安く集める＝**離脱の量産**。
- **③ 価値観**：そもそも **継続に価値を置く人** かを最初に見極める。

> ※「身もふたもない」がそのまま選別装置になる：希望中毒の層は去り、購買力ある現実派が残る。

---

## 第2層：選ばれ続ける「総合格闘技」
良い池ほど競争が激しい。**スキルは"入場券"。差は"それ以外の全部"でつく。**

```
【入場券】 スキル          … 無いと入れない。でも全員ある＝差にならない
【信頼の運用】遅刻しない・マメ・コミュ力 … 年単位で効く"当たり前"の積み重ね。減点を出さない
【代替不可能性】人間性      … 同スキルの誰かでなく"あなた"を選ぶ理由
【先回りの証明】社会証明    … 体験する前から選ばれる。池の中で目立つ
```
★逆説：**池が高いほどスキルの差は消え、"それ以外の総合力"で決まる**。
→ 業界の「資格コレクター」は、入場券を増やしてるだけ。本当に選ばれてる奴は、遅刻せずマメで感じよく証拠がある奴。

### 信頼の加点：時間（引き算の唯一の例外・最高ROI）
- 海軍の **「五分前精神」**（クライアント曰く"4分前"）。**完璧な状態で4分前にそこにいる**。
- 時間通り＝それだけで加点。「この人はちゃんとしてる」と思われる。
- ★**halo（後光）**：一度そう思われると、**本人が他で多少ちゃんとしてなくても"ちゃんとしてる人"として解釈される**＝他の減点を見逃してもらえる。**加点(時間)が引き算(減点回避)に奉仕する**。
- コストはほぼゼロ（規律と準備だけ）。なのに反応が圧倒的に変わる＝**全フレームワークで一番ROIが高い行動**。
- 肝は「**完璧な状態で**」。バタバタ4分前着はダメ。整って・落ち着いて・準備済みで、4分前にいること。
- ※同じ trust加点 ＝ 社会証明（第2層の「先回りの証明」）。dazzle（華・面白さ）と違い、安く・消えず・haloを生む。

### 最強因子：感じがいい ＝ "しんどくない"
全要素の中で最強。ただし定義が逆：
> 感じがいい＝魅力的（足し算）ではなく、**毎週会ってもしんどくない（引き算）**。
- 結果は頭打ちになる。価格は抜かれる。スキルは並ぶ。でも**「会うのが楽」だけは飽きず、コピーできず、年単位で効く**。
- "しんどくない"の中身（何を**しない**か）：
  - 機嫌が一定（顔色を伺わせない）／自分語り・承認欲求が出ない（相手が主役）
  - 否定・ジャッジしない（気を抜ける）／重くない・押し付けない（距離が楽）／ネガティブを持ち込まない
- 一言：**相手にエネルギーを使わせない。会うコストがゼロに近い。** これが52週×14年で積み上がる。
- wowは飽きる。楽は飽きない。**un-fakeable**（年単位だとエゴ・重さ・不機嫌は必ず漏れる）。

## 第3層：外見 ＝ 生理的ゲート（減点のみ・完璧でゼロ）
最も原始的なゲート。**外見の臨界点を踏むと、スキルも感じのよさも出番が来ない**（関係が始まる前に終わる）。
- ❌ 世間：外見は加点 → ⭕ 真実：**減点のみ。完璧でゼロ。気持ち悪い要素は全部マイナス。**

```
減点チェック（即アウト因子）
 清潔：肌・匂い・鼻毛・ヒゲ・爪 ← 「生理的に無理」が出る最頻ポイント
 整え：歯並び・髪型             ← 放置＝"だらしない"の信号
 足元・末端：靴・靴下           ← 一番見られて一番サボる
 全体：色の使い方               ← 過剰・チグハグは"気持ち悪い"側へ
→ 全部完璧で、ようやく"減点ゼロ"。プラスは無い。どれか欠けると即アウト。
```

### 原理①：減点は"美醜"でなく"信号"
客は外見そのものでなく、そこから **「安全か／雑に扱われないか／信用していいか」** を読む。
- **爪**：見た瞬間「**この手で私の体に触るのか**」。汚れてなくても、雑なら**"体の扱いも雑"**と推論され即アウト。
  → 爪は美醜でなく、衛生・丁寧さ・体への敬意の**信号**。
- 匂い：近距離への耐性の信号。歯並び・髪：自己管理の信号。
- ★減点＝「気持ち悪い」だけでなく、**「この人にサービスを受けて大丈夫か」のNOサイン**。

### 原理②：臨界点はサービスの物理で決まる／基準は"最も厳しい観察者"
- **触れる仕事は、手・爪・匂いが最前線**（客の不安が集まる場所）。業種が違えば不安の在り処も違う。
  → 教訓：**自分のサービスで"客の生理的不安がどこに集まるか"を特定し、そこを最優先で消す**。
- **「シビアに見ている人は必ずいる」**＝最も厳しい一人を基準に線を守る。**一人に減点を見られたら終わり**。誰が見てるかは選べない。

※ 旧整理「見た目は単価に効く（加点）」は本層で上書き：**見た目は加点でなく、減点を踏むと即アウトの生理的ゲート**。

## 語る資格：目撃者の権威 ＋ AI時代の堀
- **資格＝経歴でなく実体験**：15年・最長14年・日本最上位の池で選ばれ続けた**目撃者**。
- **AI時代に経験だけが値段を持つ**：理論はAIが無限に吐く＝コモディティ。だが**一次経験は生成不能＝唯一の堀**。
- **反論できない権威**：「効かない」→「14年効いた」で終了。
- **guru化しない保険**：全主張が実際の記憶に紐づく。
- ★発信規律：**具体を削るな**。鼻毛・靴下・アメリカンクラブ・14年——生々しさ自体が"経験の証拠"。一般論に磨くと弱くなる。

## 横展開（他業種への落とし込み方）
理論は業種非依存。各業種で「池・価格・価値観・総合格闘技・外見の臨界点」を当てるだけ。
- ピラティス/ヨガ（証明） → 治療院・整体・教室・サロン → 対人サービス全般。
- 教えるのは「あなたの業種での"アメリカンクラブ"を作れ／見つけろ」。
