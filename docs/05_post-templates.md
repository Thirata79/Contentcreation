# 05. 投稿構造テンプレ＋量産手順

ネタを**量産可能な形**にするための4テンプレ。
1つの現場課題を、4つの型で書き分けると4投稿になる（→ ネタが4倍に増える）。

---

## 型①：問題ラベル型（認知・共感）
痛みに**名前**をつける。検索・引用の入口。

```
【現場あるある】
〈場面〉で〈具体的な困りごと〉、ありませんか？

これ、〈痛みのラベル名〉問題です。
原因は気合い不足じゃなくて、〈構造的な一言〉。

放置すると〈起きる損失（現場言語）〉。
```
例：
> 予約の電話、レッスン中に取れなくて折り返し…ありませんか？
> これ「予約取りこぼし」問題です。
> 原因は接客の問題じゃなくて、受付がその場にいないと予約できない構造。
> 放置すると、来たかった人が他店に流れます。

---

## 型②：構造分解型（信頼・権威）
**なぜ起きるか**を分解する。因果を見せる。

```
〈現場の困りごと〉が起きる理由を分解すると：

1. 〈要因A〉
2. 〈要因B〉
3. 〈要因C〉

ボトルネックはたいてい〈どれか〉。
ここを〈仕組み〉で外すと、〈改善〉する。
```

---

## 型③：再現性型（リード化・テンプレ導線）
**誰でも真似できる手順**にする。

```
〈課題〉を〈時間/コスト〉で減らす手順：

Step1. 〈やること〉
Step2. 〈やること〉
Step3. 〈やること〉

これだけで〈結果〉。
ひな形が要る人いますか？（→ note / テンプレ配布）
```

---

## 型④：業界横断型（SaaSの市場提示）
**他業種でも同じ**だと示す＝市場の広さを見せる。

```
これ、ジムの話に見えて〈業種〉でも全く同じです。

・ジム　　：〈例〉
・空手道場：〈例〉
・治療院　：〈例〉

業種が違うだけで、構造は「予約制レッスンビジネス」で同一。
だから解き方も1つで済む。
```

---

## 量産手順（ネタ→投稿）
1. **ネタを1つ選ぶ**（下の在庫から）。
2. **現場言語に翻訳**（`04`のルール）。
3. **4つの型で書く**（①〜④）。当たりそうな型から出す。
4. **メタデータを記録**（`posts.csv`）。
5. 反応を見て **勝ち型をテンプレ化→note→ツール化**。

### ネタ在庫（戦略ブリーフ由来）
- トレーナーの見た目と売上の関係
- 靴・服装が与える印象
- LTV意識（継続・離脱）
- Web設計の裏側（予約までの段差）
- 予約対応時間の問題
- ギフト設計（紹介・再来）
- 費用対効果意識（時間あたり利益）
- LINE手作業 / 無断キャンセル / 回数券管理 / ダブルブッキング / 値付け
