# 11. フィットネス系クリエイターの実情（市場地図）

> 「映え」の裏側を、身もふたもなく地図にする。
> ここを直視するほど、`docs/08`（継続＝空き地）と `docs/01`（業務OS設計者）の正しさが立つ。
> ＝ **同じ土俵で殴り合うのをやめる**ための、敵情視察ドキュメント。

---

## 結論（先に置く）
```
フィットネス系クリエイターの99%は「集客の顔」で殴り合っている。
だが現場の血は「集客」ではなく「継続」から出ている。
→ 全員が入口（集客）で渋滞し、出口（継続・LTV）はガラ空き。
```
だから戦うべきは「もっと映える」「もっとバズる」ではない。
**みんなが見ていない実情（＝続かない／食えない構造）を握ること**。

---

## ① 数字で見る実情（希望でなく真実）

### 食えてる人の分布
| 区分 | 年収レンジ | 実態 |
|---|---|---|
| 雇用（社員・契約・バイト） | 約300〜415万円 | 正社員が少ない＝**辞める人が多い**から雇用が安定しない |
| フリー／個人 | 約200〜1,000万円超 | レンジが極端。**集客が外れると200万を割る** |
| 上澄み（一部） | 1,000万円超 | 存在するが、全体から見れば**例外**。これを見て参入する |

> ポイント：平均値は「中央の人が食えてる」を意味しない。
> **少数の上澄みと、大量の200万円未満が同居**しているだけ。
> 「映える上澄み」だけがSNSに出るので、実情が歪んで見える。

### SNS収益化の実情
| よくある誤解 | 実際に起きていること |
|---|---|
| フォロワー1万人で食える | 1万人でも収益化できないアカウントは普通にある |
| 案件は大きい | ヨガ系の初案件で報酬5,000円、という現実 |
| 投稿し続ければ伸びる | 収益化まで**半年〜1年**。その間に多くが脱落 |
| バズれば安泰 | **アルゴリズム変更1回で露出と収入が激減** |
| フォロワーが資産 | 「10万人のフォロワーより100人のファン」が真実 |

→ **集客（フォロワー獲得）はフロー。穴の空いたバケツに水を注ぐのと同じ**（→ `docs/08`）。

## ② プレイヤー類型（誰が何で戦っているか）

```
┌─ A. 映え・ビジュアル型 ──────────────┐
│  痩せた/鍛えた身体・ビフォーアフター     │ 飽和。再現性の証明がない
├─ B. ノウハウ量産型 ───────────────┤
│  「痩せる○つの方法」「神トレ」          │ コモディティ化。誰でも言える
├─ C. 集客コンサル型 ───────────────┤
│  「ジムの新規を増やす」「広告運用」      │ 激戦。MOSH等のSaaSと正面衝突
├─ D. 資格・養成スクール型 ─────────┤
│  「インストラクターになろう」           │ 供給を増やす側＝飽和の加速装置
└─ E. 継続・LTV型 ─────────────────┘
     離脱を止める／指名・紹介が回る側     ← ほぼ無人（＝我々の陣地）
```

> A〜Dは全員「新規（集客）」を取り合っている。
> Eだけが「既存（継続）」を握る。**競合の地図上で唯一の空き地**（→ `docs/08`）。

## ③ なぜ全員が「集客の顔」に寄るのか（構造）

| 引力 | 中身 |
|---|---|
| felt pain が強い | 客の痛みは「**客が来ない**」。ここが一番ビビッと反応する＝バズる |
| 成果が見える | フォロワー数・新規数は数字で映える。継続率は地味で見えない |
| 供給が増え続ける | 養成スクール（D）が毎年新人を量産→**集客競争が永久に激化** |
| プラットフォーム最適 | SNSは新規露出装置。継続の話はアルゴリズムに乗りにくい |
| 誤診される | 離脱は「客が合わなかった」と**客のせいにされ**、問題として認識されない |

→ だから「集客」は永遠に飽和し、「継続」は永遠に無人。
**構造がそうさせている**ので、放っておいても空き地は埋まらない。

---

## ④ 実情の核心：上澄みの「再現性のなさ」

映えてる上澄みクリエイターの強さは、多くが**属人**（顔・身体・キャラ・たまたまのバズ）。
- 真似できない（再現性がない）＝フォロワーは増えても**他人の問題は解決しない**
- だから「すごいけど、で、私はどうすれば？」で終わる
- ＝ **教育コンテンツとして弱い**。憧れは売れても、現場は回らない

我々の非対称な強み（→ `docs/01` `docs/09` `docs/10`）：
```
属人の「すごさ」で勝負しない。
15年の暗黙知を「再現できる手順（業務OS）」に変換して売る。
→ 映えでは負けても、「現場が回る」では誰も追ってこない。
```

## ⑤ この地図から導かれる打ち手

| 実情 | 我々の動き |
|---|---|
| 全員が集客の顔で渋滞 | 入口は集客の痛みを借り、**継続に着地**（→ `docs/08` 発信アーキテクチャ） |
| 上澄みは属人で再現性なし | **手順化・テンプレ化**で「真似できる」を売る（→ `docs/05` `docs/10`） |
| SNS収益は不安定・フロー | フロー（発信）→ストック（継続設計・伴走・月額）へ流す（→ `docs/02` 3層構造） |
| 養成D が供給を増やし続ける | 「**増やす側**」でなく「**続けさせる側**」に立つ（永久に空いている） |
| 離脱は誤診される | 「客のせい」を「**設計の問題**」に翻訳する＝署名メッセージ（穴の空いたバケツ） |

## ⑥ 一行サマリー
> **フィットネス系クリエイターは全員「集客の顔」で渋滞している。**
> **血が出ているのは継続。だから我々は、映えで戦わず「続く現場」を設計して売る。**
