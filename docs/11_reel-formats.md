# 11. リール向けバズ型ライブラリ（国内外）

主戦場＝インスタのリール。ここでは **リールでバズっている"形（フォーマット）"** を国内外から集めて、
本アカウントのネタ（継続×AIで仕組み化）に当てはめる。`docs/06`（X/LinkedIn等のテキスト型）のリール版。

> **大原則（`sns-neta.md` 運用ルールと同じ）**：型（フォーマット）は輸入する／中身（トピック・市場）は輸入しない。
> 骨格・フック構文・尺・カット位置だけ借りて、中身は自分の独占領域に差し替える。
>
> **使い方**：1つのネタ在庫を、複数の型で書き分けて量産 → `content/posts.csv` に反応を記録 → 勝ち型に寄せる（＝最初の30本＝型探し）。

---

## 0. 共通の土台（全型に効く前提）

- **フック3秒**：視聴者の約半分が最初の3秒で残る/離れるを決める。結果の約7割はフックで決まる（国内複数ソース）。
  - **1行目は「音声」でも「画面テロップ」でも成立させる**（音オフ勢・音オン勢の両取り）。
- **尺**：教育/ノウハウ系は **15〜30秒が黄金**（ループしやすい）。talking-head の権威系は 30〜60秒まで可。60秒超は基本正当化しにくい。
- **編集リズム（標準）**：2〜3秒に1カット、無音の間を作らない。国内の「**2カットの法則**」＝最初の2秒で2回カット＝フィード上で画が動いて目を引く。
- **テロップ（標準）**：85%以上が音オフ視聴 → ノウハウ系はテロップ必須。国内定石：中央・位置固定、太ゴシック、1画面2〜3行（5〜6行で離脱）、フォントは全編1つ、1要素1〜2秒。
- **アルゴリズム2026**：滞在（retention）に加え、**コメント・シェア・保存**が"運用側でコントロールできる信号"として重み増。→ 賛否が出る型／保存したくなる実用型が有利。
- **反ポリッシュ原則**：作り込み過ぎ・CM臭は逆効果。「役に立つより先に広告に見えたらスクロールされる」。**素の talking-head の方が信頼される。**

> **★佇まいの原則との整合（ここが我々の武器）**：`sns-neta.md`「バズ音・過剰テロップ・キラキラをやらない／静かに格を出す」は、
> 2025-26のトレンド（反ポリッシュ＋calm-premiumが伸びる）と一致している。**我々のブランド制約は、いま追い風。**
> だから本アカウントの既定ラッパーは下の【型13 カーム・ミニマル talking-head】。他の型もこの佇まいに乗せて使う。

## 1. 型ライブラリ（talking-head 中心・厳選）

> ダンス/ミーム/トレンド音源系は本アカウントの佇まいと合わないため除外。
> 各型末尾の「当てはめ」は `sns-neta.md` のネタ在庫番号（#1〜）。

### 型R1｜具体アウトカム・フック（最も刺さる系）
- **出所**：グローバル英語短尺（retentionデータ）。約45%のフック率。
- **なぜ効く**：具体性（「〇〇な人向け」を絞る）が"自分ごと化"と信憑性を同時に上げる。
- **骨格**：`1行目＝具体的な結果＋具体的な相手 → その仕組み一個 → 証拠/細部 → payoff → 軽いCTA`
- **尺/編集/テロップ**：20〜40秒、2〜3秒カット、数字は大きく。
- **当てはめ**：#3「実力より認知度」→「フォロワー3人でも継続率で食える。技術発信で埋もれてる指導者へ」

### 型R2｜逆張り／Unpopular Opinion（賛否＝コメント誘発）
- **出所**：グローバル。LinkedIn×Reels。約38%フック率・エンゲージ約3倍。
- **なぜ効く**：通説への反論はコメント・保存・引用を生む。ネガ/摩擦フックは肯定形の1.3〜1.8倍のフック率。
- **骨格**：`「みんな〇〇と言う。実は逆」→ 通説 → なぜ間違い → 根拠（構造）→ 正しい一手`
- **尺/編集/テロップ**：25〜45秒 talking-head、やや遅めでも論で持つ。逆張り主張をテロップ強調。
- **当てはめ**：#1「集客に金かける前に継続直せ」／#6「海外のバズを日本で真似しても伸びない（市場構造）」

### 型R3｜「やめろ」型（Stop doing X）
- **出所**：グローバル。フィットネス系 talking-head の定番オープナー。
- **なぜ効く**：即・摩擦＋損失回避。「それ、逆効果です」の一撃。
- **骨格**：`「〇〇、やめてください」→ なぜ逆効果 → 代わりにこれ → 細部一個 → CTA`
- **尺/編集/テロップ**：20〜40秒、1テーマ1Tips。"やめろ"の語を太字。
- **当てはめ**：型C全般／#5「肩書き（トレーナー）で発信するのやめてください」

### 型R4｜共感／If you（痛みの名指し）
- **出所**：グローバル 教育/コーチ系。
- **なぜ効く**：痛みを名指し＝「見られてる感」→自分ごと化。calm/minimalに最も乗る。
- **骨格**：`「〇〇で悩んでるなら、これはあなたに」→ 悩みを言語化して肯定 → 解決 → payoff`
- **尺/編集/テロップ**：20〜35秒、直カメラで温度。
- **当てはめ**：#3／#5「トレーナーとして続けることに、実は不安がある人へ」

### 型R5｜痛みの先読み・問いかけ（＝国内「悩み提起型」）
- **出所**：国内ノウハウ系（保存最多ジャンル）。
- **なぜ効く**：「これ知らないと損」「〇〇で困ってない？」で痛みから入る→保存率↑→発見タブに乗る。
- **骨格**：`①冒頭2秒:悩みから入る → ②3秒:得られる具体メリット明示 → ③本編:2秒おきカットで解決策 → ④まとめ+保存CTA`（100万再生級の"黄金構造"）
- **尺/編集/テロップ**：1分以内、本編2秒カット、テロップmute対応必須。
- **当てはめ**：#看板・型A「客が辞める理由、料金でも効果でもないんですよ」

### 型R6｜結論先出し（国内定石）
- **出所**：国内リール標準。
- **なぜ効く**：冒頭2秒で payoff を宣言（「〇秒で変わる」「答えはこれ」）→ 曖昧さを消して2秒の滞在を買う。
- **骨格**：`冒頭2秒で結論宣言 → 悩み提示 → 解決策(3つ以内) → 保存したくなるまとめ+軽CTA`
- **尺/編集/テロップ**：15〜30秒、2カットの法則、中央太ゴシック2〜3行。
- **当てはめ**：#4「AI時代に残る仕事、2つだけです」

### 型R7｜ターゲット絞り込み（国内「〇〇な人だけ見て」）
- **出所**：国内。
- **なぜ効く**：呼びかけで自分ごと化、対象だけ残る＝濃い視聴者。
- **骨格**：`「〇〇な人だけ見て」→ 悩みの言語化 → 解決策 → CTA`
- **尺/編集/テロップ**：15〜30秒、呼びかけを全画面テロップで。
- **当てはめ**：#1「駆け出しで新規が取れない人だけ見て」

### 型R8｜リスト型（[N個]・国内は3つ以内）
- **出所**：グローバル教育の中核／国内は「解決策3つ以内」。
- **なぜ効く**：数字が中身と尺を予告→保存率↑。教育系は保存/シェアで全カテゴリ最強。
- **骨格**：`「〇〇の[3]つの間違い」→ 1 → 2 → 3（最後が hook の約束を回収）→ まとめ+保存CTA`
- **尺/編集/テロップ**：25〜45秒、項目ごと直カット、番号バッジ。**3つまで**。
- **当てはめ**：発信の3原則／#4の「承認欲求の満たし方3つ」

### 型R9｜3つの後悔／I wish I knew（権威×弱さ）
- **出所**：グローバル短尺の定番。
- **なぜ効く**：経験（権威）＋リスト明快さ＋弱さ（共感）。「少し先を行く案内人」に見える。
- **骨格**：`「〇〇する前に知りたかった3つ」→ 各教訓＋具体例一個 → CTA`
- **尺/編集/テロップ**：30〜45秒、b-roll最小、保存狙い。
- **当てはめ**：#5「トレーナー時代に知りたかった3つ」

### 型R10｜Before/After・数字の証拠
- **出所**：グローバル。フィットネス/コンサルで最強の視覚証拠。
- **なぜ効く**：脳は"変化"に反応。視覚証拠は文章の証言に勝つ。**新規撮影がなくても数字（継続◯ヶ月→◯ヶ月・予約数）でも可。**
- **骨格**：`hookで結果/対比 → 出発点 → 方法/転機 → 結果 → CTA`
- **尺/編集/テロップ**：15〜45秒、分割/リビール、タイムライン表記（Week1→Week12）。
- **当てはめ**：型D（道場・ジム案件）。**★型Dの受け皿がこれ＝在庫でDが空なので最優先で撮る。**

### 型R11｜誤解訂正（Myth vs Fact／期待vs現実）
- **出所**：グローバル。誤解を正すフィットネス系に強い。
- **なぜ効く**：誤解訂正＝権威化＋信頼。対比は見やすい。
- **骨格**：`通説/期待 → 「現実は：」→ なぜ誤解が続くか → 正しいやり方 → CTA`
- **尺/編集/テロップ**：20〜40秒、2カラム/前後対比テロップ。
- **当てはめ**：型A／#2「"感じの良さ"は才能じゃない。減点をゼロにしてるだけ」

### 型R12｜リアクト／画面提示（画面を見せて解説）
- **出所**：グローバル（グリーンスクリーン/react）。
- **なぜ効く**：スクショ・記事・コメントを背景に専門家の見解を足す。低制作・高権威。
- **骨格**：`hookで対象にリアクト → 証拠を指す → 専門家解釈 → 学び → CTA`
- **尺/編集/テロップ**：30〜60秒、1テイク、テロップで論を運ぶ。
- **当てはめ**：**型E（開発の裏側）＝ meshilog/trelog の画面を見せて解説。在庫でEが空なのでここで撮る。**

### 型R13｜カーム・ミニマル talking-head（＝本アカウントの既定ラッパー）★
- **出所**：2025-26の逆張りトレンド（"静かな/新章"系が伸びている）。
- **なぜ効く**：ジャンプカット疲れへの解毒。**micro-pause（間）が注意をリセット**、「画を呼吸させると視聴者が前のめりになる」。calm-premium＝考え抜かれた/格上に見える。
- **骨格**：`静かで確信のあるhook（叫ばない・言い切る）→ 一個の考えを丁寧に → 一拍の間 → payoff → 控えめCTA`
- **尺/編集/テロップ**：15〜90秒（完走狙いは7〜30秒）、1カット15〜25秒＋意図的な間、**バス音のSFXなし**、静かな語り、テロップは Montserrat/Inter/Poppins 等で小さく前寄せ・位置固定、字幕はあるが派手なアニメなし。
- **当てはめ**：**全型の"包み"。** R1〜R12の骨格を、この静けさに乗せて出す＝差別化。

## 2. 佇まいを守る「採取ルール」（何を借り、何を捨てるか）

| 借りる（型・骨格） | 捨てる（佇まいに反する） |
|---|---|
| フック構文（具体/逆張り/やめろ/結論先出し等） | バズ音・効果音のドロップ |
| 尺・カット位置（2秒/2カットの法則） | 過剰テロップ・キラキラ装飾・全画面アニメ |
| 保存/コメントを誘発する構造 | 煽りすぎ・釣りだけで中身なし |
| 音オフ対応の字幕 | フォント混在・毒々しい配色 |

- 既定ラッパーは **R13カーム・ミニマル**。他型もこの静けさに乗せる。
- 「採取＝パクリ」ではない。中身（独占領域の解像度・本音）は自分にしか出せない → **型が同じでも別物になる。**
- 海外クリエイター名を出す時はリスペクト前提（#6メモ参照。disり構文にしない）。

## 4. 型 × ネタ在庫 マトリクス（どのネタをどの型で撮るか）

| ネタ在庫 | 相性の良い型 |
|---|---|
| #1 弱者の経営戦略（打席） | R2 逆張り／R7 ターゲット絞り込み |
| #2 感じが良い人＝減点ゼロ | R11 誤解訂正／R13 カーム |
| #3 職人気質が苦戦（実力より認知） | R1 具体アウトカム／R4 共感／R5 悩み提起 |
| #4 承認欲求＋エンタメ（AIに残る2つ） | R6 結論先出し／R8 リスト／R2 逆張り |
| #5 埋もれた話（やりたくなかった） | R9 3つの後悔／R3 やめろ／バックストーリー |
| #6 海外バズは日本で厳しい（市場構造） | R2 逆張り／R12 リアクト |
| 型D 数字の事例（※在庫空） | **R10 Before/After・数字** ←最優先で素材化 |
| 型E 開発の裏側（※在庫空） | **R12 リアクト（画面提示）** ←ここで撮る |
