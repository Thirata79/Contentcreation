# 02. メディア構想

## 最終コンセプト
```
現場改善メディア（予約制ビジネス特化）
= 予約制レッスンビジネスの「業務OSメディア」
```

## 検討の経緯
| 段階 | 案 |
|---|---|
| 初期 | 「現場の悩みを解決！」「対人サービスの業務最適化」 |
| ブラッシュアップ | 現場改善メディア／予約制ビジネス特化／業務OSメディア |
| 最終 | **現場改善メディア（予約制ビジネス特化）** |

---

## 3層構造（収益化までの設計）

```
┌─────────────────────────────────────────┐
│ フロント：メディア（SNS）                  │ ← 認知・信頼。現場の違和感を発信
├─────────────────────────────────────────┤
│ 中間：業務改善コンテンツ                    │ ← テンプレ/チェックリスト/note。リード化
├─────────────────────────────────────────┤
│ バック：SaaS・ツール化                      │ ← 予約・LINE・回数券などを仕組みで解決。収益の本丸
└─────────────────────────────────────────┘
```

## 成長フェーズ（コンテンツの役割が変わる）
1. **現場の違和感発信** … 「あるある」で刺し、共感と信頼を貯める
2. **構造化** … なぜ起きるかを分解。「再現できる説明」に変える
3. **テンプレ化** … 真似できる手順・ひな形を配る（リード獲得）
4. **ツール化** … テンプレで回らない部分をSaaSに載せる（マネタイズ）

> 各フェーズで投稿の8割は「現場課題」、2割で「構造・実験」を見せる。
> 概念は **テンプレ/ツールへの導線がある時だけ** 出す。

---

## 対象（誰の何を解決するか）
- **対象**：予約制レッスンビジネスの個人〜小規模オーナー（1〜数店舗）。
- **痛み**：予約・連絡・継続管理が **属人化** していて、現場が回らない／時間が奪われる。
- **約束**：その痛みを「気合い」ではなく **構造とツール** で減らす。

## トーン
- 上から教えない。**同じ現場に立っていた人間**の目線。
- 抽象語を使ったら必ず現場の具体に着地させる。
